# Security Policy

## Supported versions

Only the latest release receives fixes. Upgrade with:

```sh
go get -u github.com/ypopivniak/msx
```

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ypopivniak/msx/security/advisories/new)
instead. Include the affected version, a description of the issue, and a
minimal reproduction if possible.

You can expect an initial response within a week. Once a fix is released,
the advisory will be published with credit to the reporter unless you
prefer to stay anonymous.

Vulnerabilities in Media Station X itself should be reported to its author;
see [msx.benzac.de](https://msx.benzac.de/).
